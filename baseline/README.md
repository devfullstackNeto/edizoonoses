# EDI Zoonoses V2 - demonstração integrada

Abra `index.html` em navegador moderno. Não requer servidor.

## Novidades da V2
Dashboard ampliado, prioridade/risco/qualidade, mapa/hotspots sintéticos, croqui, chatbot com fonte/fallback, OCR workflow, repositório com classificação/hash demo, qualidade de dados, analytics/model card, administração, relatórios/export e auditoria.

## Integridade
Dados 100% sintéticos. OCR, mapa e analytics são demonstrações de workflow. O pacote `04_Contexto_Codex_Final` especifica a implementação funcional completa com backend, banco, PostGIS, storage, OCR real, RAG, RBAC e testes.
